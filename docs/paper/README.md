# Paper Documentation Index

This directory is the frozen fact base for paper writing. It records completed
experiments and their evidence, without changing models, datasets, code, or
results.

| File | Purpose | Status |
| --- | --- | --- |
| `PAPER_FINAL_STATUS.md` | Current final research status and scientific boundaries | FROZEN |
| `PAPER_EVIDENCE_MAP.md` | Evidence, verification status, and paper gaps | FROZEN |
| `PAPER_TABLES.md` | Source-backed tables for manuscript drafting | FROZEN |
| `PAPER_METHOD_PIPELINE.md` | Text pipeline and implementation correspondence | FROZEN |

Use the cited result files as the primary numerical provenance. Historical
documents elsewhere in the repository remain preserved and are not replaced by
this directory.
